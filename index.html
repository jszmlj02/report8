📌 作品介绍

一款面向游戏运营场景的 AI 自动化工具原型，模拟「运营数据 → AI 推理 → 结构化周报」的完整工作流，解决游戏运营每周手工整理周报耗时 2-4 小时、质量不稳定的痛点。

① 一键生成：输入版本更新、核心数据（DAU / 7日留存 / 付费用户 / ARPPU）与玩家反馈，自动产出结构化运营周报
② 智能诊断：识别环比趋势与舆情关键词，自动判定本周运营风险等级（高风险 / 较高 / 中等）
③ 数据归因：将数据变化与版本内容关联分析（等级上限→DAU 增长、限时副本→留存窗口），输出归因结论
④ 行动清单：按 P0 / P1 / P2 优先级输出下周行动项、负责方与截止日期
⑤ 方法论沉淀：自动生成下周 KPI 预测与运营方法论总结，可沉淀为团队周报模板

技术实现：HTML / CSS / JavaScript 交互原型，内置规则引擎模拟 LLM 推理（关键词识别 + 逻辑判断 + 模板渲染），支持一键填入演示数据快速体验，体现「用 AI 工具解决运营提效问题」的产品化思维。
